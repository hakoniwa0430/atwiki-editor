# Wikiとの接続・同期・投稿

Atwiki Editorを使うと、Wikiのページをパソコンに取り込んで編集し、変更した本文をWikiへ送れます。この説明では、ブラウザで見る公開先のWikiを「本家」、パソコンに保存したページを「手元のファイル」と呼びます。

初めて使うときは、**接続する → ページを取り込む → 編集して保存する → 内容を確認して投稿する** の順に進めてください。

## 操作メニューの開き方

1. VS Codeで `Ctrl` + `Shift` + `P` を押します。
2. 画面上部に出る検索欄に「アットウィキ」と入力します。
3. 一覧から使いたい操作を選びます。

この検索欄を「コマンドパレット」と呼びます。以下では、一覧に表示される「アットウィキ: 」を省略して操作名を記載します。本文の比較や投稿は、編集中の画面を右クリックしても選べます。

## 初回の準備

パソコンにインストールしたVS Codeを使います。また、接続するWikiの管理者として、管理画面の「基本設定」から **OAuth アプリ管理** を開ける必要があります。この項目がないWikiでは接続できません。

### 1. ページを保存するフォルダを用意する

1. パソコンに、このWiki専用のフォルダを作ります。
2. VS Codeの「ファイル」→「フォルダーを開く」で、そのフォルダを開きます。
3. フォルダの内容を信頼するか確認されたら、自分で用意したフォルダであることを確認して信頼します。

複数のフォルダを開くと保存先が分かりにくくなるため、初めはWiki用のフォルダだけを開いてください。

### 2. Wiki側で接続の準備をする

1. ブラウザでWikiの管理画面を開き、「基本設定」→ **OAuth アプリ管理** に進みます。
2. アプリを登録します。アプリ名には `Atwiki Editor` など、用途が分かる名前を入力します。
3. 「HTTPSリダイレクトURI」には、次の文字列をそのままコピーして入力します。

   `https://vscode.dev/redirect`

4. 権限を選ぶ「スコープ」欄で、次の4つを有効にします。画面上の名前と照らし合わせて選んでください。

   | 選ぶ項目 | 用途 |
   | --- | --- |
   | `user:read` | 接続したアカウントの情報を確認する |
   | `wiki:read` | Wikiのページを読み取る |
   | `wiki:write` | ページを作成・更新する |
   | `offline_access` | 接続を継続して利用する |

5. 登録後に表示される `client_id` と `client_secret` を、次の手順でコピーできるようにしておきます。

`client_id` と `client_secret` は、VS Codeから接続するために使う情報です。特に `client_secret` は他人に見せたり、Wikiの本文に貼り付けたりしないでください。自分のWebサイトやサーバーを用意する必要はありません。

### 3. VS Codeから接続する

1. VS Codeの操作メニューから **Wikiに接続（OAuth）** を選びます。
2. 接続するWikiのURLを入力します。例えば `https://w.atwiki.jp/sample/` の形式です。`sample` のようにWikiの個別名だけでも指定できます。
3. 続いて、Wikiの管理画面に表示された `client_id`、`client_secret` をそれぞれの入力欄にコピーします。
4. ブラウザが開いたら、アットウィキにログインして連携を許可します。
5. 「Visual Studio Codeを開く」などの確認が出たら許可します。VS Codeに戻り、「接続しました」と表示されれば完了です。

接続中は、操作を始めたVS Codeのウィンドウを開いたままにしてください。ブラウザのURLをコピーして戻す必要はありません。10分以内に完了しなかった場合は、最初から接続をやり直してください。中止する場合は、VS Codeの進捗通知でキャンセルします。

接続情報はVS Codeに保存されます。普段の利用では毎回入力する必要はありません。「再接続してください」と表示されたときに、同じ手順で接続し直してください。接続先はVS Codeで開いたフォルダごとに保存されます。フォルダAで hoge、フォルダBで fuga に接続すると、以後は対象ファイルの所属フォルダに応じて自動で切り替わります。複数のフォルダは「ワークスペースにフォルダーを追加」で同時に開けます。通常のサブフォルダは所属するワークスペースフォルダの接続を使います。独立したWikiとして使う場合は、そのフォルダをVS Codeで開いて接続してください。

以前のバージョンの接続情報は、対象フォルダで「Wikiに接続（OAuth）」を実行し、「以前の接続を引き継ぐ」で移行できます。接続解除も選択したフォルダだけに適用されます。フォルダの移動・名前変更後は接続し直してください。

## Wikiのページを取り込む

1. 保存先のWiki用フォルダがVS Codeで開かれていることを確認します。
2. **Wikiの全ページを取得・同期** を選びます。
3. 完了の通知が出るまで待ちます。読み取り可能なページが、ページ名に `.atwiki` を付けたファイルとして保存されます。
4. VS Codeの左側にあるファイル一覧から、編集したいページを開きます。

**すでに同名のファイルがある場合は、本家の本文で上書きします。手元で編集した内容を残したいときは、全ページの取り込みを実行しないでください。** 編集中のページだけを確認したい場合は、後述の **Wikiの最新更新と比較** や **現在のページだけ同期** を使います。

保存済みのファイルは直接上書きされます。一方、画面上に未保存の編集がある場合、その編集は残ります。後から保存すると取り込んだ本文を上書きしてしまうため、全ページを取り込む前に、残したい編集を別の場所にコピーしておいてください。

ファイル名に使えない文字は置き換えられ、長い名前は短くなります。その結果、別のページでも同じファイル名になる場合があります。また、複数フォルダを開いている場合は、編集中のファイルがあるフォルダを使い、該当しなければ保存先のフォルダを選択します。

## 編集してWikiへ投稿する

1. 取り込んだファイルを開き、本文を編集します。
2. `Ctrl` + `S` で保存します。**Wikiへ送るのは保存済みの内容です。未保存の編集は送られません。**
3. **差分を確認して本家へ投稿** を選びます。
4. 左側に本家の本文、右側に投稿する保存済みの本文が表示されます。変更点を確認します。
5. 確認メッセージのページ名と投稿先URLを確かめ、**この内容を投稿** を選びます。
6. 「投稿完了」と表示されたことを確認します。

投稿すると、そのページの本文全体が保存済みの内容に置き換わります。キャンセルすれば投稿しません。ファイルに保存しただけでは本家は更新されません。

**Wikiを更新（1ファイルを指定）** から、投稿するファイルを1つ選ぶこともできます。編集中の画面の右上にある雲と上向き矢印のボタンでは、その画面のファイルを更新します。左側のファイル一覧で対象を右クリックしても実行できます。

投稿するファイルは、この拡張機能で取り込んだもの、または **ページを追加** で作ったものを使ってください。ファイルを移動したり名前を変えたりすると、投稿先との対応が分からなくなり、投稿できなくなります。

## 本家の変更を確認・取り込みする

### 変更点だけを確認したいとき

対象のファイルを開き、**Wikiの最新更新と比較** を選びます。左側に本家の最新本文、右側に手元の本文が表示されます。右側には未保存の編集も含まれます。この操作では本文を書き換えたり、投稿したりしません。

### 今開いているページだけ取り込みたいとき

**現在のページだけ同期** を選びます。「同期」は、本家の変更を確認して手元のファイルへ取り込む操作です。手元の内容を本家へ送る操作ではありません。

| 状態 | 操作後の結果 |
| --- | --- |
| 本家と手元の本文が同じ | 本文は変わりません。 |
| 手元だけを編集している | 手元の編集を残します。 |
| 本家だけが更新されている | 本家の最新本文を編集画面へ取り込みます。内容を確認して `Ctrl` + `S` で保存してください。 |
| 本家と手元の両方が変更されている | 自動では書き換えず、比較画面を開きます。次の手順で内容を整理してください。 |

### 「双方に変更があります」「競合」と表示されたとき

これは、手元で編集している間に本家も更新され、どちらの内容を残すか確認が必要な状態です。

1. 比較画面の左側にある本家の変更を読みます。
2. 残したい内容を手元の本文にコピーするなどして、投稿したい本文に整えます。
3. **競合解決済みとして同期基準を更新** を選びます。
4. 本家との比較をもう一度確認し、必要な変更を取り込めていれば **統合済みとして基準を更新** を選びます。
5. 手元の本文を `Ctrl` + `S` で保存し、あらためて投稿します。

手順4は「本家の変更を確認して取り込んだ」と記録するための操作です。本文の保存や投稿は行いません。内容を整理する前に押さないでください。本家がさらに更新された場合は、再度比較して確認します。

## 新しいページを追加する

1. Wiki用フォルダを開き、**ページを追加** を選びます。
2. 新しいページ名を入力して確定します。
3. 本家に空のページが作成され、手元にもファイルが保存されて編集画面が開きます。
4. 本文を書き、保存してから投稿します。

**ページ名を確定した時点で、本家にページが作成されます。** 誰が閲覧・編集できるかは、Wikiの標準設定に従います。同名のファイルが保存先にある場合は、作成を中止します。

本家への作成後に手元への保存が失敗した場合は、通知にその旨が表示されます。同じページをもう一度作ろうとせず、本家に作成されていることを確認してください。取り込み直す場合は、先に手元の編集を別の場所へコピーし、全ページの取り込みによる上書きに備えてください。

## ページの画像について

ページを取り込むと、Wikiに置かれた公開画像も可能な範囲で自動取得します。本文の画像指定を書き換える必要はなく、取得できた画像はプレビューで表示できます。

ページに添付された画像は「ページ名」のフォルダ、Wiki内で共通利用する画像は `pub` フォルダに保存されます。再度取り込むと、同名の画像も本家の内容に更新されます。本文の編集を整理する必要がある場合でも、画像の取り込みは行われます。

本文と画像の取得結果は別々に報告されます。1ページにつき先頭200件の画像URL、1画像につき20MiBまでが対象です。画像名にWindowsで使えない文字が含まれる場合などは取得できません。現在のページだけの同期で、別ページの画像を取得できなかった場合は、全ページの取り込みで取得できることがあります。ただし、手元の本文が上書きされる点に注意してください。

## 困ったとき

| 表示・状況 | 対処方法 |
| --- | --- |
| 接続が完了しない | 操作を始めたVS Codeのウィンドウに戻って確認します。時間切れの場合は接続をやり直してください。 |
| 「未接続のファイル」と表示される | Wikiから取り込んだファイルか確認してください。自分で作ったファイルや、移動・改名したファイルはそのまま投稿できません。 |
| 「本家が更新されています」と表示される | **Wikiの最新更新と比較** で確認し、上記の「競合」の手順で本文を整理します。 |
| 投稿中に通信が切れた | 本家への投稿だけは完了している可能性があります。まず **Wikiの最新更新と比較** で確認してください。本文が同じなら、再度投稿操作をしても送信せず、確認済みとして記録します。 |
| 「一部失敗」と表示される | 通知にあるページ名や画像のエラーを確認します。他のページの取り込みは完了している場合があります。 |
| 結果の通知を見失った | VS Codeの画面下部にある「アットウィキ: …」をクリックすると、直近の結果を再表示できます。ウィンドウを再読み込みすると、この表示はリセットされます。 |

## 接続を解除する

**Wikiとの接続を解除** を選ぶと、VS Codeに保存された接続情報を削除します。Wiki側でも連携の許可を取り消したい場合は、本家の **OAuth アプリ管理** で操作してください。

接続を解除しても、手元の本文や画像は残ります。また、変更を比較するために前回取り込んだ本文などもパソコンに保存されています。非公開ページの本文も含まれるため、接続解除だけで取り込んだ内容がすべて消えるわけではありません。

## 未対応の機能・制限

| 項目 | 未対応の内容・対処方法 |
| --- | --- |
| ページの削除 | 外部連携APIの `wiki:delete` スコープは将来対応予定のため、拡張機能では未対応です。本家で削除してください。対応するローカルファイルも自動削除しません（[公式ガイド](https://w.atwiki.jp/guide/pages/3135.html)）。 |
| ページ名の変更 | 本家で操作してください。 |
| タグ・概要の更新 | 本文の投稿では変更しません。本家で編集してください。 |
| 複数ファイルの一括投稿 | 1ファイルずつ差分を確認して投稿してください。 |
| 移動・改名したファイルの投稿 | ページとの紐付けを引き継ぎません。再取得が必要です。未接続のファイルも投稿できません。 |
| 競合の自動マージ | 行単位の自動統合は行いません。双方に変更がある場合は手動で統合してください。全ページ同期ではローカルの変更を保護しません。 |
| 画像・添付ファイルのアップロード | ローカル画像の追加・変更は送信しません。本家の「このページにファイルをアップロード」から手動で操作してください（[公式外部連携API v1](https://w.atwiki.jp/guide/pages/3135.html)は添付ファイル操作に非対応）。 |
| 画像の削除・双方向同期 | Wikiからの画像取得のみ対応しています。 |
| 非公開・外部などの画像取得 | 非公開ページのHTML、ログインが必要な画像、外部サイトの画像、本文にも公開HTMLにも現れない添付画像は取得対象外です。 |
| 本家の編集履歴の取得・比較・復元 | 過去の版の一括取得や比較、ローカルへの復元は未対応です。[公式API](https://w.atwiki.jp/guide/pages/3136.html)に履歴取得用の公開エンドポイントがなく、Web画面の解析も未実装です。「Wikiの最新更新と比較」は現在の本文との比較です。 |
