# リリースノート

## 1.1.0（2026-11-11）

- OAuthによるWiki接続、全ページの取得・同期、競合検出、差分確認後の投稿、ページ追加に対応。フォルダごとに接続先を管理できます。
- サイドバーに「Wikiとの差分」を追加。本家・ローカル・双方の変更と未取得ページを一覧表示し、最新本文との比較を開けます。
- 現在のページと画像アップロード画面をブラウザで開く操作を追加。
- 「/」を含むページ名のリンクに対応し、aname未指定のアンカー移動・補完候補を抑制。
- WebP変換の既定値を容量優先の非可逆圧縮（画質80）に変更。既存の明示的な設定は維持します。
- プレビューの処理上限など、安定性と入力処理を改善。

### 対応環境と更新

VS Code 1.92.0以降に対応し、配布VSIXはWindows x64向けです。拡張機能IDは変更していないため、1.0.xから更新できます。OAuth接続にはWiki管理画面の「OAuth アプリ管理」での準備が必要です。接続情報はフォルダ単位で管理するため、フォルダの移動・名前変更後は再接続してください。

本家アットウィキの完全互換ではありません。導入は[インストールと使い方](getting-started.md)、接続・同期・投稿と制限事項は[Wikiとの接続・同期・投稿](wiki-sync.md)を参照してください。

## 1.0.1（2026-11-10）

- ページ名と同じフォルダー内の画像を優先して表示するページ別画像管理に対応。従来のページと同階層の画像も利用できます。
- PNG・JPEG・GIF・AVIF・TIFF画像のWebP変換を追加。変換のみ、または画像参照の更新を選択できます。
- 可逆／非可逆圧縮と画質設定、元画像の保持／削除に対応。同名WebPは上書きせず、参照更新や保存に失敗した場合は元画像を保持します。
- WebP変換用のライブラリとライセンスをVSIXに同梱。

### 対応環境と更新

最低対応版をVS Code 1.92.0に変更しました。GitHub Releasesの配布VSIXはWindows x64向けです。他のOS・CPUでは対応する環境でソースから生成してください。拡張機能IDは変更していないため、1.0.0から同じ拡張機能として更新できます。

APNGとGIF以外の複数フレーム画像は変換対象外です。参照の自動更新はワークスペース内の `.atwiki` / `.atw` が対象です。

導入・更新手順と新機能の操作は[インストールと使い方](getting-started.md)を参照してください。

## 1.0.0（2026-11-06）

初回リリース。アットウィキ記法の編集とローカルプレビューに対応します。

### 収録機能

- アットウィキ記法の構文強調、入力補完、ホバー、診断、ライブプレビューとスクロール連動。
- 表、目次、折りたたみ、数式、コードハイライト、アイコン、QRコードなどのローカル描画。
- ローカルページ・画像・添付ファイルの参照、ページ取り込み、検索、アンカー移動。
- ページ名の自動リンクと除外ページ設定。
- Wikiの最新更新と編集中の本文の差分比較。
- テーマとPC／モバイル表示モード、外部画像・埋め込み・RSS/Atomの取得設定。

### 対応範囲と制限

VS Code 1.85.0 以降を対象とします。本家アットウィキの完全互換ではなく、サーバー固有の情報や一部記法はローカル向けの代替表示です。詳細は[記法の対応状況](../COMPATIBILITY.md)を参照してください。

導入・更新手順は[インストールと使い方](getting-started.md)を参照してください。
