# リリースノート

## 1.0.0（2026-11-06）

現在の実装を 1.0.0 の基準版として整理しました。開発中に使用した 1.0.1 / 1.0.2 から機能を巻き戻す変更ではありません。拡張機能IDは `atwiki-local-tools.atwiki-local-preview` のままです。

### 収録機能

- アットウィキ記法の構文強調、入力補完、ホバー、診断、ライブプレビューとスクロール連動。
- 表、目次、折りたたみ、数式、コードハイライト、アイコン、QRコードなどのローカル描画。
- ローカルページ・画像・添付ファイルの参照、ページ取り込み、検索、アンカー移動。
- ページ名の自動リンクと除外ページ設定。
- 編集履歴の保存、差分比較、復元。
- テーマとPC／モバイル表示モード、外部画像・埋め込み・RSS/Atomの取得設定。

### 対応範囲と制限

VS Code 1.85.0 以降を対象とします。本家アットウィキの完全互換ではなく、サーバー固有の情報や一部記法はローカル向けの代替表示です。詳細は[記法の対応状況](../COMPATIBILITY.md)を参照してください。

外部埋め込みとRSS取得は既定で無効です。既存の実画面検証ではRSS一覧を表示できましたが、YouTube・ニコニコ動画の埋め込み内再生やXプロフィールのタイムライン表示は成功していません。[検証記録](verification.md)に確認範囲と結果を記載しています。

インストール済みの開発版から切り替える手順は[インストールと使い方](getting-started.md)を参照してください。
