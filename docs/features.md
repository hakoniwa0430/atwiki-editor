# 機能概要

- 入力に追従するプレビュー、スクロール連動、本文から編集行への移動
- 記法・オプション・ローカルページ・画像・アンカーの入力補完
- 表、目次、折りたたみ、数式、コードハイライト、アイコン、QR コードの描画
- ローカルページの参照・取り込み・検索
- 現在の本文にあるページ名をリンク構文へ一括変換
- Wikiの最新更新と編集中の本文の差分表示
- OAuthによるWiki接続・本文の同期・競合検出・確認後の投稿
- 外部画像、動画・SNS の埋め込み、RSS/Atom の表示

記法ごとの対応状況は [COMPATIBILITY.md](../COMPATIBILITY.md) を参照してください。本家アットウィキとの完全互換ではなく、一部はローカル向けの代替表示です。

## プレビューの上限

動作が重くなることを防ぐため、本文の長さ（100万文字）とプレビューの処理量に上限があります。上限に達した場合は「プレビューの処理上限に達したため、表示を中止しました。」と表示します。本文の編集・保存は引き続き行えます。
